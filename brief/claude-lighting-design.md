## 1. 任务概述

**任务：** 为一部已有的舞台剧设计灯光。选定剧本后，你需要针对剧中**两个形成对比的场景**，做出一套完整的、可被执行的灯光设计方案。

**产出性质：** 纸面设计（folio），不需要实际搭建灯位或现场演示。评审看的是你的**图纸、表格与标注剧本**能否让一个不了解你想法的人，在脑中把这两场戏放一遍。

**核心难点（提前知道会省很多时间）：**

- 两个场景必须**形成对比**——这是最常做不好的地方。
- 设计概念不能只停留在「实用」或「字面」层面（例如「这是夜晚所以用蓝光」）。要有一个能贯穿的设计主张。
- 四份文件（平面图 / Cue Sheet / 标注剧本 / 灯具色片表）之间必须**编号与名称完全对应**。

## 2. 交付物清单

| # | 文件 | 说明 |
|---|------|------|
| 1 | **设计说明**（约 300 词） | 以「导演概念」的口吻写：分析剧作的中心动作，给出连贯、一贯的解读与制作愿景。不算分，但评审会据此确认你的意图。 |
| 2 | **灯光平面图** | 针对 2 个场景，比例 **1:25**。手绘或 CAD 均可，CAD 需打印成纸质件。 |
| 3 | **Cue Sheet** | 一张总表，按顺序列出所有灯光 cue（给灯光操作员看）。 |
| 4 | **标注剧本 / 提示本** | 剧本本体，在台词与动作旁就地标出 cue 编号（给舞台监督「叫 cue」用）。 |
| 5 | **灯具与色片清单** | 列出两个场景用到的灯具、色片，并说明它们对戏剧动作、气氛、风格的影响。 |

**平面图必须包含：**

- 舞台平面图，标明重要布景元素（floor plan + set features）
- 灯具位置图（lantern positions）
- 色片（gel）颜色、使用的灯具，以及每盏灯覆盖的区域
- 上述灯具与色片的清单与说明

**装裱提示：** 不要使用玻璃（运输与评审过程中的安全问题）；用简单的卡纸装裱即可。

## 3. 设计质量的三个维度

任何灯光设计最终都会被从这三个方向看。理解它们，能让你知道力气该花在哪。

| 维度 | 看什么 |
|------|--------|
| **1. 概念 / 愿景** | 对剧作的解读是否有效、完整、原创、清晰？灯光设计是否真的为「关键时刻」贡献了戏剧冲击力？ |
| **2. 恰当性** | 灯光状态与变化是否强化了戏剧动作、气氛、风格？灯具、位置、色片颜色、亮度的选择是否达成了照明目的？灯光是否（在适当处）强化了布景的视觉元素？ |
| **3. 执行** | 概念在平面图中的落实程度；平面图、Cue Sheet、提示本三者的**清晰与准确**。 |

**分档参考（执行维度）：**

- 高分：设计概念在平面图中被完整实现；三份文件清晰且准确。
- 中档：**adequate but superficial** —— 平面图、Cue Sheet、提示本在细节与一致性上参差不齐。
- 低分：平面图有实质缺陷；**提示本或 Cue Sheet 可能不完整或缺失**。

> 注意最后一句：很多设计者只做漂亮图纸，提示本潦草，直接掉档。

## 4. 读本与概念确立

**步骤：**

1. **把整部剧读 2–3 遍**，做场次分析，标出所有「灯光能说话」的时刻。
2. **定下导演概念**：一句话说清中心动作 + 你的解读。
3. **选 2 个形成对比的场景** —— 这一步是全任务最重要的决定（见第 10 节）。
4. 为这两场各画一张**光区草图**（不必是最终 1:25 平面图）：标出哪里要亮、哪里要暗、色温怎么走。

**写设计说明的四段式：**

1. 一句话点明整体意图 / 概念。
2. 你探索的关键瞬间、想法、意象、手法、风格惯例。
3. 你调度了哪些戏剧与设计元素，它们如何制造戏剧意义。
4. 对预期观众反应的反思。

> 设计说明应该在开发过程中**反复改写**，而不是最后补写。它的作用是澄清意图、为你的选择辩护。

**一个好用的自检：** 找一个完全没看过你设计的人，只给他设计说明，问他「这部戏你要用光表达什么」。答不出来，说明概念还没成型。

## 5. 灯光平面图（1:25）

**比例必须是 1:25。** 手绘或 CAD 都可以，CAD 需打印成纸质件。

**要画出来的东西：**

- 舞台平面与布景元素（简化为宜）
- 灯具位置（用标准符号标注，每盏灯给编号，如 `F1` `K1` `US` `S1` `B1`）
- 每盏灯的覆盖区域（光区），用不同填充或线条区分
- 色片颜色与灯具型号的标注

**一个反直觉的建议：** 布景越简单，越利于展示灯光。复杂的布景会挤压灯位空间，也让图纸难以读清。**简单的布景反而是灯光设计的优势。**

**光区命名建议**（贯穿所有文件使用同一套编号）：

```
F1–F3   前区面光
K1–K2   厨房区 / 主要室内区
US      后区 / 二楼
S1–S2   侧光
B1      背景楼体轮廓
```

编号一旦定下，平面图、Cue Sheet、标注剧本三份文件必须**完全一致**。

## 6. Cue Sheet 怎么写

### 6.1 先搞清楚：要的是两份文件

交付物里有两件容易混淆的东西：

- **Cue Sheet** —— 一张总表，按顺序列出所有 cue（给灯光操作员看）
- **标注剧本 / 提示本（prompt copy）** —— 剧本本体，cue 点就地标出（给舞台监督「叫 cue」用）

> **「标注剧本」和「提示本」是同一个东西。**

两份文件必须**互相对得上**：Cue Sheet 里的 `Q7`，在标注剧本上必须能在同一句台词旁找到 `Q7`。抽查的就是这个一致性。

**最常见的失分：** 只交表格没有标注剧本；或者剧本上乱画箭头但没编号。

### 6.2 列该怎么设

行业里没有唯一标准格式，但以下列是通行做法。**加粗的 6 列是必须有的。**

| 列 | 填什么 |
|---|---|
| **Q No.** | cue 编号，`Q1` `Q2` `Q3`… 按演出顺序。开演前状态用 `Q0.5` |
| **Page / Act-Sc** | 你的剧本版本的第几页、第几幕第几场。例：`p.12 / Act 1` |
| **Cue Point** | 触发点，精确到**一句台词或一个动作**。例：「Linda 说完『Willy, it's all right…』之后」或「门关上时」 |
| **Lighting State** | 这一 cue 之后画面变成什么样。含：哪些光区亮/暗、色片颜色、强度感觉、台上被照亮的是哪里 |
| **Lanterns / Gel** | 涉及哪些灯位编号与色片。例：`F1–F3 (L201), S1 (L132), US wash (L711)` |
| **Fade Time** | 单位秒。升降不同写两个：`Up 3s / Down 8s`；交叉淡化写 `X-fade 5s` |
| *Intensity*（可选） | 百分比或 0–10 级 |
| *Notes*（可选） | 给操作员的提示：「必须完全无声」「与音乐 cue 3 同步」「缓慢隐去，不可抢戏」 |

**排版建议：** 一个场景一张表，或两个场景合成一张但用「Scene」列分隔。两场之间用横线或空行隔开，让读者一眼看出分界。

### 6.3 Cue 编号规则

- **按演出顺序从 1 开始**，不跳号、不重号。
- 行业惯例前缀 `LX`（= Electrics，即灯光），书面可写 `LX Q1`；直接写 `Q1` 也完全可以，**但要在表头说明你的编号方式**。
- **开演前的状态用 0.x**：`Q0.5` 通常指 house lights（观众席灯）或 preset（预设状态）。这样 `Q1` 就能留给演出中的第一个真 cue。
- **要插入新 cue 时用小数**：在 Q2 和 Q3 之间加一个 → `Q2.5`。**绝对不要**把后面全部重新编号 —— 你的标注剧本上已经写好编号了，重编号必然对不上。
- **两场独立编号还是连续编号？** 两种都行。连续编号更像真实演出；独立编号更便于分场分析。**必须在表头写清楚。**

### 6.4 Fade Time 怎么写

- **单位统一用秒**，写 `3s` 或 `3 sec`，不要写「快」「慢」。
- **升和降不同就分开写**：`Up 2s / Down 10s`。
- **交叉淡化**：一个状态替换另一个状态，写 `X-fade 5s`。
- **瞬间变化**写 `0s` 或 `snap`（例如枪响、停电、黑场）。**snap 要慎用** —— 一整场全是 0s，会显得没有设计感。
- **Blackout 也要编 cue**：写 `Q12 — Blackout, 0s` 比不写专业得多。

> **为什么时间要有理由：** fade time 本身就是戏剧语言。8 秒的缓慢暗场和 1 秒的硬切，观众感受完全不同。建议在 Notes 列或设计说明里点明：这个时间是为了什么效果。

### 6.5 Cue 点必须钉在可执行事件上

舞台监督要能在那一瞬间喊「Go」，所以：

- ❌「大约在场景中段」
- ❌「在这段话中间」
- ✅「Linda 说完『Willy, it's all right』之后」
- ✅「门关上时」
- ✅「音效起音的同时」

### 6.6 空白模板

```
Q No. | Page/Act-Sc | Cue Point (trigger) | Lighting State | Lanterns/Gel | Fade Time | Notes
------|-------------|---------------------|----------------|--------------|-----------|------
Q0.5  |             | House open          |                |              |           |
Q1    |             |                     |                |              |           |
Q2    |             |                     |                |              |           |
```

（完整 20 行版本见同目录的 `cue-sheet-template.csv`。）

## 7. 标注剧本 / 提示本（prompt copy）

**做法很直接：把剧本打印出来，在 cue 点旁边标出 cue 编号。**

### 两种标注方式

- **页边标注法**：在剧本右边留白处，对准那一行写 `Q7`，下面画一条竖线延伸到下一行，表示这个灯光状态持续到哪。
- **行内插入法**：在台词之间插入一行醒目的 `==== Q7 / X-fade 5s ====`。

两种都建议**加上简短的状态描述**（如 `Q7 — memory wash in, kitchen out`），让人不用来回翻 Cue Sheet 就能读懂。

### 标在哪一行（这是核心技能）

```
LINDA: Willy, it's all right. I'll make you a sandwich.
◀ Q7   X-fade 6s   kitchen down / memory wash up (L201 + L132)
(WILLY does not answer. The boys' laughter drifts in from off-stage.)
◀ Q8   3s   US wash to 40%, add S2 (L711) leaf pattern
WILLY: (softly) Biff… Biff…
```

### 别做的事

- 不要在剧本上只画荧光笔不写编号
- 不要只标第一场的 cue
- 不要用不同颜色但没有图例

> 你的标注剧本是给一个**完全不了解你想法的人**执行用的。

## 8. 完整范例

以下为示范用的填写范例。**设计选择为虚构，仅示范格式与颗粒度。**

### 场景设定

**剧本：** *Death of a Salesman* — Arthur Miller
**第一场：** Act 1，Loman 家厨房，深夜。现在是「现实」——冷调、局促、被公寓楼的阴影压迫。
**导演概念（一句话）：** Willy 的世界里，「过去」比「现在」更亮 —— 灯光要让观众在他分不清回忆与现实之前，就先从光里感觉到这一点。

**光区（与平面图对应）：** `F1–F3` 前区面光｜`K1–K2` 厨房区｜`US` 后区／二楼卧室｜`S1–S2` 侧光｜`B1` 背景楼体轮廓

### Cue Sheet — Scene 1 (Act 1, kitchen / night)

| Q | Page | Cue Point | Lighting State | Lanterns / Gel | Fade | Notes |
|---|------|-----------|----------------|----------------|------|-------|
| Q0.5 | — | House open（观众入场） | House lights 满亮；舞台 preset：背景楼体 B1 微弱轮廓 | House / B1 (L120) | — | 开演前状态 |
| **Q1** | p.11 | 开场前哨音（sound cue 1）结束后 | House 全暗。舞台只剩 B1 楼体剪影 + K1 微弱冷光，整体压到近乎全黑 | B1 (L120) @15%, K1 (L201) | Up 4s / Down 2s | 营造「夜归」的压迫感 |
| **Q2** | p.11 | Willy 放下行李箱、坐下（开场后第一个动作） | K1 厨房区升到 60%，冷蓝白，硬边。K2 冰箱区 30%。F1 侧前方补一点轮廓 | K1 (L201), K2 (L201), F1 (L201) @20% | Up 3s | 不许照亮 US 卧室区 |
| **Q3** | p.12 | Linda 在二楼卧室开口：*"Willy? Are you all right?"* | US 卧室区亮起，暖钨丝色（2700K 感），与厨房冷调形成对照；卧室成为视觉焦点 | US (L132) @55%, K1 降至 40% | X-fade 4s | 卧室永远是暖的 —— 这是全剧「过去／家」的色标 |
| **Q4** | p.13 | Linda 下楼、走进厨房 | K1 回到 60%；US 保持 40%（两人同时「活着」） | K1 (L201), US (L132) | Up 2s | 两人同框时不要出现单一光源的「舞台感」 |
| **Q5** | p.14 | Willy 说 *"The car kept going off on me"* 后，Linda 转身开冰箱 | 冰箱灯亮起一瞬（实用光源效果），色温偏冷，短暂打亮 Linda 半张脸 | Practical — fridge (LED, L201 滤色) | 0s on / 2s off | 与冰箱门的实际动作同步，需在排练中校准 |
| **Q6** | p.15 | Willy 第一次提起 Biff：*"Biff is a lazy bum!"* | K1 轻微下压到 45%，色温不变但整体感觉「缩紧」；F1–F3 前区面光降至 10% | K1 (L201), F1–F3 (L201) | Down 5s | 极慢 —— 观众不该「看到」灯在动 |
| **Q7** | p.16 | Willy 独白开始：*"Biff Loman is lost…"* —— 他坐下来，声音变柔 | 冷调开始「变质」：K1 从 L201 交叉到 L132（暖琥珀），亮度 55%。B1 楼体剪影开始渗入树叶图案（gobo） | K1 (L132), B1 + gobo "leaves" | **X-fade 12s** | **全场最重要的一个 cue** —— 用 12 秒的极慢交叉，让「现实」在观众还没意识到时就变成了「过去」 |
| **Q8** | p.16 | 少年 Biff 与 Happy 的笑声从场外传来（sound cue 2 起音） | US 区扩展到全后区，暖金色 wash 满铺；S1–S2 侧光加入，制造树影与纵深；K1 降到 25% | US wash (L132 + L103), S1–S2 (L132), B1 gobo | Up 6s | 必须与音效起音**同时**，不可提前 |
| **Q9** | p.17 | Willy 走进回忆区、离开厨房桌面 | 厨房区 K1–K2 完全暗去；全台只剩暖金回忆光，边界柔和、无硬边 | K1–K2 down, US/S1–S2 up | X-fade 8s | 观众应感到「现在」被关掉了，而不是「灯灭了」 |
| **Q10** | p.19 | 本场结束 —— Linda 的画外音把 Willy 拉回现实 | 暖金 wash 快速抽离（4s），K1 冷光硬切回来（snap），色温回到 L201。B1 楼体剪影重现 | US/S1–S2 down, K1 (L201) up, B1 | Down 4s / Up 0s | 「硬切回现实」是设计意图：Willy 每次被拉回现实都是被**打断**的 |

### 对应的标注剧本片段

```
WILLY: Biff Loman is lost. In the greatest country in the world a young
       man with such — personal attractiveness, gets lost.
▶ Q7   X-fade 12s   K1: L201 → L132 (amber) @55%  |  B1 + leaves gobo
(He sits, and the kitchen begins to lose its edges.)
▶ Q8   Up 6s   US wash + S1–S2 amber  |  sync with SOUND Q2
(Off-stage, the laughter of YOUNG BIFF and HAPPY.)
▶ Q9   X-fade 8s   K1–K2 out  |  full memory state
```

> 注意：剧本上只写**编号 + 时间 + 关键变化**，完整状态描述留在 Cue Sheet 里 —— 这样剧本可读，表格详尽，两者互为索引。

### 第二场怎么形成对比

上例第一场是「冷现实 → 暖回忆」。如果第二场选 **Act 2 的餐厅／Boston 旅馆场景**，就可以做完全相反的走向：**「暖 → 冷崩塌」** —— 让同一套色片逻辑反转，观众会立刻感到 Willy 的世界在瓦解。

好的两场组合应该是**镜像或对位**关系，而不是「同一部戏里随便两段」。

**自问：** 这两场的光，能不能让人看出我作为灯光设计者的**创作广度**？

## 9. 候选剧目与灯光友好度分析

以下十部舞台剧可作为设计文本的候选（也可自行替换）。**评级为分析性建议，仅供筛选**，最终应选你真的喜欢、且读完后有话想说的那部。

### ★★★★★ 最顺手的三部

**1. The Visit（Dürrenmatt, 1957）** — 悲喜剧／荒诞 · 三幕 · 大群戏

一个小镇为了钱集体杀死旧日情人。剧本天然自带**强烈的灯光对比**：开场是破败、灰暗、等火车的绝望小镇；Claire 携巨款归来时是金色、奢靡、几乎超现实的光；结尾的集体审判则需要阴影、红光、人群包围的压迫感。

- 对比场景建议：Act 1 车站等待（冷、灰、晨光）↔ Act 3 体育馆审判（暖金变质为血色、大量侧光与剪影）
- 为什么好做：光的「温度」几乎就是剧情的隐喻 —— 金钱让小镇变暖，也让小镇变脏。概念清晰，图纸有内容可画。

**2. Death of a Salesman（Miller, 1949）** — 现实主义／表现主义元素 · 两幕 + Requiem

剧本结构本身就是「现在 ↔ 回忆」的不断切换，而**原作舞台提示里就大量依赖灯光**来完成这种切换。灯光在这个戏里不是装饰，是叙事工具。

- 对比场景建议：Act 1 厨房（冷现实 → 暖回忆）↔ Act 2 餐厅／Boston 旅馆（暖 → 冷崩塌）
- 要注意：正因为原作对灯光规定得很细，你的挑战是**既要尊重剧本、又要提出自己的解读**。别只是把原作的灯光指示抄一遍。

**3. Antigone（Sophocles）** — 古希腊悲剧 · 单一场景 · 歌队

希腊悲剧在露天日光下演出，这反而给了现代灯光设计一个绝佳的切入点：**你要用什么光去替代太阳？** 强烈的单一光源、低角度侧光、巨大的阴影、墓穴中的黑暗 —— 这是最能用「少」做出「强」的文本。

- 对比场景建议：Creon 宣布判决的公共场景（高、白、正、冷，像审讯）↔ Antigone 在墓穴中的独白（近乎全黑，只有一道光／一点暖）
- 为什么好做：不需要复杂布景，灯的**角度与方向**就是你的全部语言，非常适合画出干净的 1:25 平面图。

### ★★★★ 各有明确抓手

**4. Tartuffe（Molière）** — 古典喜剧／讽刺 · 五幕 · 室内

关于伪善者的经典讽刺喜剧。灯光可以做得很「会说话」：Orgon 被蒙蔽时台上是饱满、温暖、甚至过分明亮的「假虔诚」光；真相揭露时颜色可以骤变、崩塌。

- 对比场景建议：Act 1 家庭争吵（明亮、均衡的室内光）↔ Act 4 桌下藏人／揭穿（极端顶光与侧光，把 Tartuffe 打成剪影或丑角）
- 为什么好做：喜剧允许夸张，你可以用色彩做**道德评论**（例如只给 Tartuffe 一个人冷绿色的光）。

**5. The Comedy of Errors（Shakespeare）** — 闹剧／双胞胎误会 · 五幕 · 多地点

两对双胞胎 + 一连串误会。这类戏最大的技术需求是**让观众随时知道「现在是谁、在哪」** —— 灯光正是解决这个问题的最佳工具。

- 对比场景建议：以色彩区分两组人物／两个空间（例如 Antipholus 兄弟用暖橙 vs 冷青，两套光区在台上同时存在）；对比场景可取集市街头的热闹明亮 ↔ 修道院／结尾认亲的沉静收敛。
- 注意：别让戏变成纯粹的灯光秀，概念仍要落在「身份错乱的眩晕感」上。

**6. Girl Asleep（Whittet, 2016）** — 成长故事／奇幻

Greta 的 15 岁生日派对 → 坠入一个诡异梦境世界。剧本本身就把世界**劈成两半**：写实的 1970 年代澳洲郊区 vs 超现实的梦。

- 对比场景建议：Act 1 客厅生日派对（实用光源、暖黄、日常、甚至有点土气）↔ 梦境森林（浓艳的色片、无来源的光、飘忽的方向感）
- 为什么好做：对比是文本自带的，不需要费力论证「这两场为什么不同」。梦境的灯光规则由你定义 —— 最能展示原创概念。

### ★★★☆ 高难度高回报

**7. Mr. Burns, a post-electric play（Washburn, 2012）** — 后末日／多时代／音乐剧元素 · 三幕

三幕横跨三个时代：停电后围着火堆复述动画剧情 → 十年后的业余剧团 → 七十年后的仪式化演出。每一幕的**光源类型本身就是剧情**：火、手电、工作灯、最终的「剧场灯」。

- 对比场景建议：Act 1 篝火夜谈（唯一光源是摇曳的火，色温极暖、不稳定、面部阴影强烈）↔ Act 3 剧场演出（完整舞台灯光系统，色彩饱和、有换场）
- 注意：难度在于你要设计三种完全不同的「技术条件」。但能驾驭的话，这是**最能体现概念深度**的选择之一。

**8. Silent Disco（Philpott, 2012）** — 当代／青少年／家庭剧

一个家庭在各自的「无声迪斯科」里跳舞 —— 每个人戴着耳机听自己的音乐。同处一室，却各在不同的频道。

- 对比场景建议：派对现场（耳机指示灯的颜色可成为视觉母题，不同颜色 = 不同人物的内心世界）↔ 家庭崩溃后的静默（灯全灭或只剩单一冷光）
- 为什么可能很好做：「用颜色代表人物内心频道」是一个干净、可执行、有原创性的概念，能贯穿全剧。挑战是这是写实室内剧，你需要靠灯光撑起戏剧张力。

**9. Cyberbile（Valentine, 2013）** — 当代／纪实风格（verbatim）／青少年

关于网络霸凌与青少年生活的纪实性剧作。主题天然指向**屏幕、冷光、监视感**。

- 对比场景建议：现实中的学校／家庭（正常室内光）↔ 网络空间的攻击场景（冷蓝、屏幕光自下而上打在脸上、无来源的光、极低角度）
- 注意：这类文本的灯光容易做得「太直接」（蓝光 = 网络），需要在概念上再往前一步 —— 例如让屏幕光逐渐侵蚀现实场景的光，直到观众分不清哪个是真实世界。

### ★★★ 有额外注意事项

**10. Waltzing the Wilarra（Milroy, 2011）** — 原住民题材／音乐与舞会／历史

以 1940 年代 Perth 的 Coolbaroo Club 为背景，涉及原住民与珍珠采集历史的音乐剧式作品。

- 对比场景建议：舞厅的热闹（暖色、舞池光、音乐的律动感、旋转的镜球反射）↔ 现实／历史的残酷（冷、空、被剥夺的舞台）
- ⚠️ 注意：涉及原住民文化与创作作品时，需要遵守相关的**文化协议（cultural protocols）**，包括正确使用文化材料、尊重社区所有权。不是不能选，但需要在设计说明与过程记录中体现你对这些协议的认知与处理方式。**建议先与指导者讨论再定。**

## 10. 选文本的四个判断标准

| 标准 | 怎么判断 |
|------|----------|
| **① 两场对比够不够强** | 读完剧后自问：有没有两个场景，光可以呈现**截然不同**的世界？如果整部戏都发生在同一个房间的同一个时段，就很难做。 |
| **② 有没有「光能说话」的关键时刻** | 找那些「灯一变化，戏就转折」的瞬间：揭穿、死亡、回忆、审判、梦境。至少要有 2–3 个这样的时刻让你兴奋。 |
| **③ 布景你能不能画得出来** | 你要交 1:25 平面图。布景越复杂，图纸越难画，灯位也越难摆。**简单的布景反而更利于展示灯光。** |
| **④ 你能不能用一句话说出概念** | 设计说明的核心是「中心动作 + 一贯的解读」。如果你读完剧说不出「我要用光表达什么」，这部可能不适合。 |

**筛选起点建议：**

- 想**稳**：Antigone（布景最简单、光语言最强）或 Death of a Salesman（结构自带灯光逻辑）
- 想**炫概念**：The Visit（温度即隐喻）或 Mr. Burns（三种技术条件）
- 想**做当代、贴近自己生活**：Girl Asleep 或 Silent Disco

> 以上仅为筛选起点，务必先读完你候选的那 2–3 部再决定。

## 11. 常见错误清单

| ❌ 错误 | ✅ 正确做法 |
|---------|-------------|
| cue point 写成「大约在场景中段」 | 钉到具体台词或动作：「Linda 说完 X 之后」 |
| fade time 写「快」「慢」「慢慢」 | 写秒数：`3s`、`X-fade 12s`、`snap` |
| Lanterns/Gel 列留空或只写「暖光」 | 写具体灯位与色片编号，与平面图、色片表完全对应 |
| 只有 Cue Sheet，没有标注剧本 | 两份都要交，且编号必须对得上 |
| 剧本上画了箭头／荧光笔但没编号 | 每个 cue 点标 `Q7` 等编号 |
| 整场只有 3 个 cue（亮、暗、黑） | 关键戏剧时刻要有实质的灯光变化；两场对比要看得见 |
| 全部 cue 都是 0s 硬切 | fade time 是表达工具，该慢的地方要慢 |
| 忘了 blackout / 换场 / 中场 | 每个状态转换都要有 cue，包括结束 |
| cue 编号重号或跳号 | 顺序编号；插入用小数（Q2.5） |
| 两场混在一张表里看不出分界 | 加 Scene 列或用空行／横线分隔 |
| 概念只停留在「夜晚所以蓝光」 | 要有能贯穿全剧的设计主张 |

## 12. 建议的制作顺序

1. **把整部剧读完 2–3 遍**，做场次分析，标出所有「灯光能说话」的时刻。
2. **定下导演概念**（中心动作 + 一句话愿景），再**选 2 个形成对比的场景**。选场是这一步最重要的决定。
3. **为这两场各画一张光区草图**（不必是最终 1:25 平面图）：标出哪里要亮、哪里要暗、色温怎么走。
4. **在剧本上直接标 cue 点**（先只写编号和一行描述），这时不要纠结时间。
5. **把编号誊进 Cue Sheet 表格**，逐条补上 Lanterns/Gel 和 Fade Time。这一步会暴露「这个 cue 我其实想不清楚」，很正常，回去改。
6. **做色片表与灯具表**，与 Cue Sheet 交叉核对：Cue Sheet 里出现的每盏灯、每个色片，都必须能在表里找到。
7. **画 1:25 平面图**，灯位必须与前面所有文件一致。
8. **最后写设计说明**（约 300 词），此时你已经很清楚自己在做什么了。
9. **交叉校对**：平面图 ↔ Cue Sheet ↔ 标注剧本 ↔ 色片／灯具表，四份文件互相查一遍编号与名称。

### 关于时间投入

这份任务的实际耗时通常**比想象的多一倍**，尤其是 Cue Sheet + 标注剧本的校对工作。请把它排进时间表，而不是留到最后一晚。

一个真实教训（来自一位做过灯光设计的学生）：**「离交件两周时，我以为我做的比实际多。」** 结果只能紧急求助才赶完。

另外一句值得记住的话：**「这不是一个人的活。」** —— 多找老师、同学、做过舞台的人看你的图纸，让他们指出哪里看不懂。
