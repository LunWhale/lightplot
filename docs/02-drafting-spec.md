# 02 — 出图规范速查

> 改图纸前必看。这些数字来自 USITT 正式规范，不是我的偏好。
> 出处：USITT RP-2 (2006)、USITT GRP 5.0、USITT Lighting Documentation RP (2025)。
> 完整 PDF 在 `brief/reference/`。

---

## 1. 图纸包构成

USITT 2025 定义：完整图纸包 = **图纸 + 文字表 + 计算机文件** 三类。

| 层 | 内容 |
|---|---|
| **图纸（按比例）** | 平面图（Light Plot）、剖面图（Section）、桁架/吊挂图、详图、机架立面 |
| **图纸（不按比例）** | 系统/网络图、单线电源图、框图 |
| **文字表** | 灯具表、通道表、回路表、DMX 地址表、采购单、色片表、Cue Sheet |
| **计算机文件** | 控台 show 文件、`.vwx`/`.dwg`、MVR/GDTF、CSV patch |

**核心洞察**：每张表都是**同一份灯具记录的不同排序**。
一份规范记录 → 渲染出所有文档。这正是 `rig.yaml` + 三个脚本的结构。

## 2. 纸张与比例

### 纸张（USITT GRP 5.0 §5.1）

| 系统 | 代号 | 英寸 | mm |
|---|---|---|---|
| ANSI | C | 17×22 | 432×559 |
| ANSI | D | 22×34 | 559×864 |
| 建筑 | C | 18×24 | 457×610 |
| 建筑 | D | 24×36 | 610×914 |

公制：平面图用 **A1 (594×841)**，发图/缩印用 **A3 (297×420)**。

### 比例（GRP §6.1 + RP-2）

| 比例 | 用途 |
|---|---|
| `1/4"=1'-0"` | 大场地平面图/剖面 |
| **`1/2"=1'-0"`** | **美国首选**的平面图/剖面比例 |
| `1"=1'-0"` | 小物件立面、详图 |
| **`1:25`** | **英国/欧洲首选**平面图比例（本项目采用） |
| `1:50` | 大场地；剖面图常用（本项目剖面用 1:50） |

**铁律**：比例必须让**所有标注在最终打印尺寸下可读**。标签挤了就换大纸，不要改比例。

## 3. 线宽（USITT GRP §2.1.2）

| 等级 | mm | 英寸 | 用途 |
|---|---|---|---|
| **细** | 0.15 | 0.006 | 视线、填充、箭头、尺寸线与引出线、置景线、台口线 |
| **中** | 0.30 | 0.012 | **物体轮廓**、注释、尺寸、灯位 |
| **粗** | 0.60 | 0.020 | **灯具符号轮廓**、剖切线、图签 |
| **特粗** | 0.70 | 0.027 | 图框、建筑外轮廓 |

**RP 2025 的细化**：
- 粗 = 灯具符号周长与设备轮廓
- 中 = 灯位/吊杆
- 细 = 符号**内部**细节、尺寸、引出线
- **灰/降低不透明度 = 布景与建筑**（弱化，让灯光先读）

代码里对应 `render.py` 的图层定义，lineweight 单位是 1/100 mm（18 = 0.18mm）。

## 4. 图层命名（GRP §7）

三段式：`专业 - 视图 - 细类`，用连字符分隔。

- **专业**：`A` 建筑 / `U` 音响 / **`L` 灯光与电气** / `S` 布景 / `C` 施工
- **视图**：`GP` 平面 / `SC` 剖面 / `EL` 立面 / `DT` 详图 / `RG` 吊挂
- **细类**：`DIMS` 尺寸 / `LABL` 标注 / `LEGN` 图例 / `NOTE` 说明 / `SYMB` 符号 / `TITL` 图签

例：`L-GP-INSTR`（灯光平面-灯具）、`L-SC-SECT`（灯光剖面）、`L-GP-RIGG`（吊挂）

**当前代码用的是简化名**（`TRUSS`/`FIXTURE`/`DIM` 等）。若要严格合规，
改 `render.py` 的 `L()` 调用即可，不影响几何。

## 5. 编号约定（RP-2 §2.3）

### 位置命名
- FOH 从**最靠台口**的往外编号
- 台上吊杆从**下场门往上场门**编号（`LX1`, `LX2`, …）
- 吊杆/梯子先 SL 后 SR

### 灯具编号
- 吊杆（垂直中心线）：**舞台左 → 舞台右**
- 台上吊杆/垂直位置：**上 → 下，下场门 → 上场门**
- 插入的灯：小号 + 字母（`3A`, `3B`）
- 多属性灯具：整数 + 小数（`23.1`, `23.2`）

### 百位编号法（常用简写）

| 区段 | 含义 |
|---|---|
| `101–199` | FOH |
| `201–299` | 1st Electric |
| `301–399` | 2nd Electric |
| `401–499` | 吊杆/梯子 |
| `901+` | 实用灯/地排/特殊 |

### 通道编号
**通道 ≠ 灯具编号**。通道按**功能/区域**分组，让设计者能把"C 区面光"作为一个通道推起来。

经典 McCandless 方案：
- `1–10` 面光（按区）
- `11–20` 逆光/顶光
- `21–30` 侧光
- `31–40` 特殊
- `41+` 效果/实用

## 6. 尺寸标注（RP-2 §3.1 / RP 2025 §3.2.1）

### 基准
- **垂直零点 = 舞台台面**
- **水平零点 = 台口线（plaster line）**
- 平面图上 trim 读**台面到吊杆底部**
- 吊杆上高度读**杆底到侧臂/灯钩**

### `+` 记号（公制/欧洲做法）
`+` = 基准之上，`−` = 基准之下，单位**毫米**。

```
+2250  → 台面以上 2.250 m（如吊杆底部）
+500   → 台面以上 0.5 m
−1800  → 台面以下 1.8 m（如乐池）
±0     → 基准本身
```

**永远注明基准是什么。**

### 其它规则
- 公制：前导零 + 小数（`0.180 m`）；超过 1 m 写 `1.500 m`
- 尺寸线距物体留 **1/16"** 间隙；文字在尺寸线上方 **1/16"**
- 箭头 **1/8"–3/16"**
- 整套图**只用一种**标注方式（单向 或 对齐）
- 精确到 **5 mm**（或 1/8"），再细是假精度

**trim 高度是剖面图上最重要的尺寸** —— 它决定光束是否打到地面、布景是否够高、吊挂是否安全。

## 7. 图签字段（GRP §8.2.3）

图签放**右下角**，从下边或右边可读，含：

- 制作单位（及联系方式）
- 剧目名
- 图纸名
- 导演 / 布景设计 / 技术总监 / 绘图者 / 审核
- 图号（"3 of 5"）
- 绘图日期
- **比例**
- 文件名（CAD 全路径）

RP-2 补充：场地、设计师、灯光助理/ME、**修订号与日期**、工会章、免责声明。

### 修订表（GRP §8.3）
图签旁或内，**最新的在最上面**，列：`修订号 | 日期 | 图号 | 说明 | 修订人`。

**永远不要静默重发**。改了就升版本、圈出改动、记录。

## 8. 灯具符号（RP-2 §6）

USITT 故意出版**通用**符号（不背书厂家），近似真实灯具的**尺寸和形状**。

| 灯具 | 平面画法 | 识别特征 |
|---|---|---|
| **成像灯（ERS/Profile）** | 细长机身，前端镜圈，闸门/镜筒 | 长度 ≈ 实际长度；标注光束角（`36°`） |
| **菲涅尔（Fresnel）** | 短圆身 + 阶梯透镜 + 遮扉环 | 圆、短粗 |
| **PAR** | 圆柱罐，近方形占位 | **灯轴箭头**表示旋转方向 |
| **LED 洗光（摇头）** | 矩形头 + 摇臂 | 摇臂 + **旋转半径圆** |
| **摇头图案/聚光** | 头 + 摇臂 + 底座 + 摆动圆 | 旋转半径包络 |
| **追光** | 大 ERS 状机身 + 支架 | 常带光束符号 + 操作位 |
| **条灯/天幕灯** | 一排小灯圆 | 显示灯数与回路（A1, A2…） |
| **实用灯** | 小灯泡/吊灯图标 | 三角或 `P` 标记 |
| **LED 灯带** | 沿表面的细线/填充 | 详图交叉引用 |

**规则**：
- 按**真实比例**画，放在**确切挂点**（灯钩，不是机身中心）
- 符号**朝向焦点**；摇头灯画**摆动半径**让 crew 知道要留空间
- 附件画在**机身相连处**：顶帽（圆）、遮扉（两线）、光圈（小圆）、图案片（小三角）
- 每种符号必须在**图例**里有定义，且图例要画**信息字段位置示意**

> **当前代码状态**：`render.py` 的 `build_symbols()` 是按上表手绘的简化版，
> 形状对了但不是厂家真实轮廓。**现已升级**：`src/gdtf_symbol.py` 从厂家 GDTF
> 提取真实轮廓（见 `docs/06-gdtf-symbols.md`），本表仅作历史记录。

## 9. 灯具表字段（RP 2025 §3.3.1）

按**位置 → 灯具号**排序。这是 crew 挂灯用的表。

| 字段 | 例 | 说明 |
|---|---|---|
| Position | `LX2` | 分组 |
| Unit | `12` | 沿杆编号 |
| Type | `ETC Source Four 750W 36°` | 含镜筒/光束角 |
| Wattage | `750 W` | 算负载 |
| Accessories | `Top hat, iris` | 遮扉、光圈、换色器 |
| Colour | `L201` | L=Lee, R=Rosco, o/w |
| Gobo | `R77851 breakup` | + 尺寸 |
| Channel | `45` | 控制组 |
| Dimmer | `112` | 电力设备 |
| Circuit | `B12` | 插座 |
| Universe/Address | `U2 / 301` | DMX 起始地址 |
| Purpose | `F/L area C warm` | 设计意图 |
| Focus | `DSC pool, chair` | 瞄准点 |
| Notes | `2-fer w/ #11` | 二通、备用 |

**派生视图**（同一数据，不同排序）：
- **通道表** — 按通道排（设计者参考）
- **回路表** — 按回路排（谁和谁共回路）
- **地址表** — 按宇宙/地址排（摇头灯 patch）
- **采购单** — 按型号排，加数量/租赁/线材/图案片/色片

## 12. 验收清单

出图后逐项打勾：

**完整性**
- [ ] 平面图（所有位置、图例、图签、说明）
- [ ] 剖面图（trim、视线、人形、遮幕）
- [ ] 灯具表（按位置）
- [ ] 通道表
- [ ] 色片表
- [ ] Cue Sheet + 标注剧本（编号对应）

**制图质量**
- [ ] 图框 + 图签完整；比例标明；修订表最新
- [ ] 线宽符合 0.15/0.30/0.60/0.70 层级；布景弱化
- [ ] 符号按比例、朝焦点、摇头灯画摆动半径
- [ ] 每种符号都在图例里；图例有字段位置示意
- [ ] 尺寸：基准注明、trim 到杆底、吊杆到侧臂、`+` 记号一致
- [ ] 编号规则有文档且一致；通道按系统分组

**数据完整性**
- [ ] 平面图、灯具表、采购单的灯具数**三者一致**
- [ ] 无重复地址；每宇宙 ≤512；留 10–20% 余量
- [ ] 回路/调光负载不超容量
- [ ] 色片/图案片数量与图上一致
